CADintosh X

A precise 2D-CAD program for technical and architectural drawings on macOS. Native performance, unlimited elements, and professional tools for engineers and architects.

Interactive Redrawing

Work seamlessly while the window redraws in real-time. No interruptions, just fluid drafting.

Advanced Pen and Line Control

Pen-oriented mode with 8 widths, colors, and pens. Individual settings from 0.0 to 99.99 mm, plus 6 line types: solid, dash, dot-dash, phantom, zigzag, dotted.

Comprehensive Toolset

Lines, arcs, dimensions, splines, hatching, and more. Supports 32,000 groups, 1,024 layers, and memory-limited elements only.

Flexible Import/Export

HPGL, DXF, PICT formats. Alternative units in inches or custom definitions. User preferences saved directly in drawings.

Symbol and Layer Management

Internal symbols limited by memory; external libraries in registered mode. Simple and extended layer filters for efficient organization.

Native macOS Performance

Runs natively on macOS, with layouts optimized for macOS Tahoe. New PDF print from print area in 8.9.1.

How It Works

1. Launch and Set Units

Open CADintosh X, define units (mm, inches, or custom), and configure pens/layers.

2. Draw with Precision Tools

Use lines, arcs, splines, dimensions, and hatching. Interactive redrawing keeps workflow smooth.

3. Organize with Layers and Symbols

Assign to 1,024 layers or insert symbols. Apply filters and check statistics for unused items.

4. Export and Print

Save in HPGL/DXF/PICT or print directly to PDF. Preferences embed in the file.

FAQ

Is this the full version?

Yes, this is the fully activated CADintosh X 8.9.1. No purchase or license required.

What file formats are supported?

Import/export HPGL, DXF, PICT. Print to PDF directly from the print area.

Are there limits on elements or layers?

Elements limited only by memory. Up to 32,000 groups and 1,024 layers.

Does it run on modern macOS?

Fully native on macOS, including Tahoe-optimized dialogs and localizations.

How do symbols work?

Internal symbols (memory-limited) plus external libraries. View unused symbols in lists and statistics.
